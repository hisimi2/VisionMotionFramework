# VMF(Vision Motion Framework) 요구사항 명세서

작성일: 2026-05-14  
대상: `VisionMotionFramework` (C++14), Equipment SW 연동 프레임워크

---

## 1. 문서 목적

본 문서는 VMF의 기능/비기능 요구사항을 정의한다.  
VMF는 UI 렌더링을 수행하지 않으며(= 화면 표시/그리기/팝업 표시 등), 결과/상태/에러 데이터만을 호스트에게 제공한다.

> 각 요구사항은 `ID`로 식별되며, 구현/테스트와의 추적은 Trace Matrix로 관리한다.

---

## 2. 용어

- **Host / Equipment SW**: VMF를 사용하는 장비 제어 응용프로그램
- **Sequence**: Task들의 실행 흐름
- **Task**: Non-blocking 상태머신 단위 실행 단계
- **Observer/Callback**: 비동기 결과 통지를 위한 함수 등록 방식
- **(UI) 렌더링**: 화면/컨트롤/그래프/오버레이 등을 “그려서 표시”하는 행위

---
